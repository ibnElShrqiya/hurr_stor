# حُرّ | HURR — متجر متعدد الصفحات

واجهة عربية RTL بهوية سوداء وذهبية، مقسمة إلى صفحات وملفات مشتركة. تم تحويل المصدر المرفق الذي كان نموذج معاينة محلياً. لا تُعرض بيانات منتجات أو أسعار مفترضة كأنها حقيقية، ولا تُسجل الطلبات قبل إعداد Supabase.

## التشغيل

1. انسخ `.env.example` إلى `assets/js/config.js` وعدّل رابط Supabase ومفتاح `anon` العام فقط. لا تضع `service_role` أو أي مفتاح سري في ملفات الواجهة.
2. نفّذ `supabase/schema.sql` في SQL Editor بمشروع Supabase. أنشئ مستخدم الإدارة من لوحة Supabase Auth، ثم أضف صفاً له في `admin_users` من بيئة موثوقة.
3. ارفع المشروع على استضافة ملفات ثابتة تدعم HTTPS، وشغّله محلياً عبر خادم ملفات (مثل `npx serve .`). لا تفتح HTML مباشرة من `file://` لأن وحدات JavaScript وطلبات الشبكة تحتاج خادماً.
4. افتح `admin/login.html` لتسجيل دخول الإدارة. صفحات الإدارة لا تمنح أي صلاحية بذاتها؛ قاعدة البيانات وRLS هما مصدر التفويض.

## الصفحات

`index.html`, `shop.html`, `product.html`, `offers.html`, `cart.html`, `checkout.html`, `about.html`, `privacy.html`, `shipping-policy.html`, `return-policy.html`, `admin/login.html`, `admin/index.html`.

الكتالوج الفعلي يُقرأ من Supabase عند ضبط الإعدادات. إذا لم يُضبط الاتصال، تظهر رسالة إعداد واضحة. السلة تخزن معرّفات المنتجات والكميات فقط في المتصفح. إنشاء الطلب يتطلب الدالة الآمنة `place_order` التي تعيد حساب الأسعار والشحن والمخزون داخل قاعدة البيانات؛ ولا يُقبل السعر المرسل من العميل.

## ما بقي قبل الإطلاق

- املأ المنتجات المعتمدة بصورها وأسعارها ومخزونها الموثق في `products`، بما فيها أسماء «الصديق»، «الفاروق»، «حفيدات عائشة» بعد مراجعة العملة والأسعار. لم تُنسخ بيانات العميل/الطلب التجريبية من المصدر.
- اضبط `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` في `assets/js/config.js` (الملف `config.js.example` نموذج آمن بمفاتيح فارغة). مفتاح anon العام متوقع في المتصفح؛ الحماية تعتمد على RLS.
- اختبر سياسات RLS بحساب زائر وحساب إدارة، وأنشئ مسؤولاً عبر قناة موثوقة. لا تجعل المستخدم قادراً على ترقية نفسه إلى مدير.
- راجع سياسة الخصوصية والاسترجاع ورسوم التوصيل، واربط مزود الدفع/الشحن عند الحاجة. لم يتم إعداد تكامل دفع أو إرسال فعلي.
- رقم واتساب في `assets/js/config.js` افتراضي فارغ: أدخل الرقم التجاري الدولي قبل الإطلاق.

## مراجعة أمان المصدر

المرفق الأصلي كان يتيح لوحة تحكم وتعديلات وحفظ طلبات عبر `localStorage` بلا مصادقة أو صلاحيات قاعدة بيانات. ذلك ليس تخزيناً مشتركاً ولا يمنع العبث. أزيل مسار الإدارة التجريبي وإعادة ضبط البيانات، ولا توجد حسابات أو طلبات تجريبية في النسخة الجديدة. سياسات RLS تمنع تعديل البيانات العامة، وتسمح بالكتابة للمديرين فقط. يجب أن تكون `place_order` دالة `SECURITY DEFINER` محدودة الصلاحيات وتتحقق من المنتج المنشور والمخزون وتعيد حساب كل الإجماليات ضمن معاملة واحدة؛ راجع SQL. لا يمكن تأكيد أمان مشروع Supabase المنشور قبل مراجعة إعداداته الفعلية واختبارها.

## تحقق

شغّل `npx serve .` وافتح الصفحات. إعداد Supabase مطلوب للكتالوج وتسجيل الدخول والطلبات. لا توجد بيانات تجريبية معروضة كبيانات حية.
