# حُرّ HURR — متجر عربي متعدد الصفحات

واجهة متجر متعددة الصفحات باستخدام HTML وCSS وJavaScript ES Modules، مع لوحة إدارة. تمت إضافة ربط Firebase للمنتجات وتسجيل دخول المدير؛ بقية الوحدات لا تزال تجريبية كما هو موضح أدناه.

## التشغيل محليًا
يتطلب المتصفح تشغيل ES Modules عبر HTTP/HTTPS، لا تستخدم `file://`.
```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## لوحة الإدارة
افتح `admin/index.html` وسجّل الدخول باستخدام بريد وكلمة مرور Firebase. يجب تفعيل Email/Password وإنشاء المستخدم وتعيين Custom Claim `admin: true` من بيئة خادمية موثوقة. بيانات الدخول التجريبية `admin / demo1234` لم تعد مستخدمة.

## حالة الربط
- **المنتجات:** قراءة المنتجات المنشورة من Firestore، وإضافة/تعديل/حذف المنتجات من لوحة الإدارة بعد تسجيل دخول مدير معتمد.
- **المصادقة:** Firebase Authentication + التحقق من Custom Claim للمدير.
- **الطلبات والكوبونات والعروض والأقسام والشحن والإعدادات:** ما زالت محلية/تجريبية ولم تُنقل إلى Firestore بعد.
- **إنشاء الطلبات:** لا تستخدم النسخة لاستقبال طلبات حقيقية حتى تنفيذ Cloud Function أو خادم موثوق يتحقق من الأسعار والمخزون والكوبونات والشحن.

## إعداد Firebase
راجع `FIREBASE-SETUP.md`، وانشر `firestore.rules` في Firestore > Rules. لا تضع مفاتيح خدمة إدارية أو أسرار خادمية في JavaScript العام. إعدادات Firebase Web في `js/config/firebase-client.js` هي إعدادات عميل عامة، ويجب الاعتماد على Authentication وقواعد الأمان لحماية البيانات.
