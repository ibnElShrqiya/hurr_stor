# حُرّ HURR — متجر عربي متعدد الصفحات

واجهة تجريبية كاملة باستخدام HTML وCSS وJavaScript ES Modules، مع صفحات مستقلة، وخدمات بيانات منفصلة، ولوحة إدارة للعرض. **لا يتصل المشروع حاليًا بقاعدة بيانات ولا يرسل طلبات حقيقية.**

## التشغيل محليًا

يتطلب المتصفح تشغيل ES Modules عبر خادم HTTP محلي؛ لا تفتح الصفحات باستخدام `file://`.

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000` من مجلد المشروع. لا توجد مفاتيح Firebase أو Supabase مطلوبة لهذه النسخة.

## صفحات المتجر

- `index.html` الرئيسية
- `shop.html` المتجر والبحث والتصنيفات
- `product.html?id=P001` تفاصيل المنتج
- `offers.html` العروض
- `cart.html` السلة
- `checkout.html` إتمام الطلب التجريبي
- `order-success.html` نتيجة الطلب التجريبي
- `about.html`, `contact.html`, `privacy.html`, `shipping-policy.html`, `return-policy.html`

## لوحة الإدارة التجريبية

ابدأ من `admin/index.html` ثم استخدم بيانات العرض `admin` / `demo1234`. هذه آلية عرض محلية فقط، وليست حماية أو مصادقة حقيقية. صفحات الإدارة تشمل لوحة المؤشرات والمنتجات والأقسام والعروض والكوبونات والطلبات والمخزون والشحن والإعدادات.

## البيانات والتخزين

- البيانات الافتراضية محفوظة في `js/data/`.
- الخدمات المستقلة في `js/services/`، وواجهة الصفحات لا تعتمد مباشرة على بنية التخزين.
- السلة والتعديلات والطلبات التجريبية تُحفظ في `localStorage` على الجهاز والمتصفح الحالي فقط.
- الطلب التجريبي لا يُرسل إلى التاجر ولا شركة شحن. المخزون التجريبي قد يتغير محليًا عند إنشاء طلب.
- الأسعار والمخزون وأوصاف المنتجات بيانات عينة قابلة للتعديل. لا تمثل معلومات تجارية مؤكدة.
- رقم واتساب مضبوط فارغًا في `js/config/app-config.js`، لذلك يظل الزر مخفيًا حتى تضيف رقم العمل الدولي من دون `+` أو مسافات.

## الأمان قبل الإطلاق

لا تستخدم تسجيل دخول لوحة العرض ولا تخزين المتصفح لإدارة متجر حقيقي. عند الانتقال للإنتاج يلزم:

1. مصادقة موثوقة للمسؤولين، مع صلاحيات خادمية لا تعتمد على إخفاء الصفحة.
2. قاعدة بيانات وقواعد وصول تمنع العملاء من تغيير الأسعار أو المخزون أو الطلبات.
3. إنشاء الطلبات والتحقق من الكوبونات والأسعار وحجز المخزون في خادم موثوق/معاملة قاعدة بيانات.
4. حماية بيانات العملاء، وتحديد مدة الاحتفاظ بها، وسياسة خصوصية قانونية ومعلومات تواصل معتمدة.
5. اختبار صلاحيات الإدارة وقواعد قاعدة البيانات، ومراجعة المدخلات وروابط الصور، واستخدام HTTPS.
